# Arduino Biofeedback Monitor

An Arduino Mega 2560 project that combines skin-conductance (GSR) input, TMP36 temperature sensing, a push button, and a 16x2 LCD. It performs a calibration period, waits for a user-triggered measurement window, and reports physiological signal changes.

## Features

- 20-second GSR calibration baseline.
- 6-second response measurement window.
- TMP36 temperature conversion to Fahrenheit.
- LCD status and result display.
- Serial output for plotting and debugging.

## Important limitation

This is an educational biofeedback project, not a validated lie detector or medical device. Physiological changes are not reliable proof of deception and should not be used for consequential decisions.
