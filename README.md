# Jayden Fernandes — Engineering Portfolio

Engineering and technical work spanning embedded systems, sensor interfaces, circuit analysis, and software-assisted engineering workflows.

## Projects

### GPS Speedometer
Raspberry Pi / Python project for parsing NMEA GPS data and converting ground speed to mph or km/h.

[View project](https://github.com/jiannef2004-source/Resume/tree/main/projects/gps-speedometer)

### Arduino Biofeedback Monitor
Arduino Mega 2560 project combining GSR input, TMP36 temperature sensing, a push button, LCD output, and serial logging.

[View project](https://github.com/jiannef2004-source/Resume/tree/main/projects/arduino-biofeedback-monitor)

### Engineering Analysis Toolkit
Python-based engineering calculators for DC power, 4–20 mA loop scaling, RC time constants, and voltage-divider analysis.

[View project](https://github.com/jiannef2004-source/Resume/tree/main/projects/engineering-analysis-toolkit)
